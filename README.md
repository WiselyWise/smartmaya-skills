# Smart Maya Agent Skills

Free, open-source AI agent skills from [Smart Maya AI](https://smartmaya.ai), built by WiselyWise Pte Ltd.

## Claude Code

Add this marketplace:

```text
/plugin marketplace add WiselyWise/smartmaya-skills
```

Install Smart Maya Tidy, a Claude Skill that audits duplicate files in Google Drive and produces an XLSX report before any approved cleanup:

```text
/plugin install smartmaya-tidy@smartmaya-skills
```

Each skill repository contains its supported-platform, security, and setup guidance.

## Available skills

- [Smart Maya Tidy](https://github.com/WiselyWise/smartmaya-tidy) — Safe Google Drive duplicate-file audit and approval-based cleanup.
